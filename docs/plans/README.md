# Implementation plans

One plan per approved design doc. A plan turns an HLD/LLD into ordered, independently
verifiable stories (Ralph-style: each story completable in one agent session, dependency
ordered, verifiable acceptance criteria, "tests pass" always included).

Format: `PLAN-<nnn>-<slug>.md` with sections: Source design docs · Milestones · Stories
(id, title, acceptance criteria, dependencies) · Verification strategy · Risks · Review log.

No plan is written before its HLD is approved.
